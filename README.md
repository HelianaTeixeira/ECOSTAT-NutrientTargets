# ECOSTAT-NutrientTargets

## Nutrient Targets - overview of approaches by Member States
This work was developed within the Water Framework Directive (WFD) Common Implementation Strategy, under the ECOSTAT Working Group. It is based on the Questionnaire presented to Member States and non-EU countries implementing WFD about the methods they used to set management objectives for nutrients, and it builds on their responses as compiled in the 2021 report by Wood Group UK Limited.

This repository contains the files necessary to complete this Report on Nutrient Targets due in 2022.
